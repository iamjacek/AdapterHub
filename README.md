# AdapterHub

Custom WooCommerce website for car audio speaker adapters and accessories.

## Project

AdapterHub is a custom WordPress/WooCommerce project focused on car-specific speaker adapters and easy DIY audio upgrades.

The project includes custom frontend design, responsive layouts and custom WordPress/WooCommerce development.

## Tech Stack

- WordPress
- WooCommerce
- Elementor
- PHP
- CSS
- JavaScript
- MySQL / MariaDB

## Custom Development

- Custom AdapterHub child theme
- Custom AdapterHub Core plugin
- Custom WooCommerce product layouts
- Custom car brand system
- Responsive navigation and layouts
- Custom product cards
- Custom Shop styling
- Responsive mobile-first design
