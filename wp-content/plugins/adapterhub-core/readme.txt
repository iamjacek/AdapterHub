AdapterHub Core 1.6.0

Custom AdapterHub functionality for WooCommerce.

Includes:
- WooCommerce Product Brand Display Order
- Dynamic car brand homepage shortcode: [adapterhub_car_brands]
- Dynamic Featured Products homepage shortcode: [adapterhub_featured_products]

Featured Products are controlled by WooCommerce's Featured flag.
No CSS is included; visual styling is controlled separately.
